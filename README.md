# Ariadne

Flugschreiber und Kartograf für Pentests unter Linux. Ariadne nimmt auf Knopfdruck Terminals, Dateien und Screenshots auf, liest daraus Hosts, Services und Zugänge aus und malt Schritt für Schritt eine Karte der Zielumgebung. Zu jedem Fakt zeigt es die Quelle. Ariadne beobachtet und gibt Denkanstösse, greift aber nie selbst an.

Status: Konzeptphase, noch kein Code.
